# Hi, I'm Antony

I'm an AI-first builder. I've been coding since fifth grade, and these days I work on personal projects in tennis video analysis, macOS tools, and automation.

## Projects

- [OpenCourtVision](https://gitlab.com/antonyvo/opencourtvision): multimodal audio and vision analysis for tennis and padel. Point detection, score tracking, and pose and stroke analysis. It runs locally on Apple Silicon. Work in progress.
- [RunReady](https://github.com/voantony/runready): checks whether a public repository still installs from its agent documentation.
- [Mount Kindle](https://github.com/voantony/kindle-mtp-mount): a macOS menu-bar app that mounts MTP Kindles as a Finder drive.
- [Library GUI for KOReader](https://github.com/voantony/koreader-library-gui): a Kindle-style home screen for KOReader with a cover grid, an A–Z strip, widgets, search, and its own gesture settings.
